# Icon attribution & licenses

Single source of truth for the provenance and licensing of the image assets under
`Assets/`. Entries are organized by **provenance** (where the art came from), not by
folder. When you add a new icon — in `ModeIcons/`, a future `FeatureIcons/`, anywhere —
add an entry here. Do **not** create per-folder `LICENSE.txt` files.

These asset licenses are independent of the project source-code license (PolyForm
Shield 1.0.0, see the repository-root `LICENSE.txt`).

## Modune brand assets — original work

The Modune geometric `M` mark and its violet-to-teal application icon were created
for this product redesign and contain no third-party artwork.

Files:
- `AppIcons/modune-mark.svg` and monochrome SVG variants
- `AppIcons/modune-mark.png` and monochrome PNG variants
- `AppIcons/modune-mark.ico`
